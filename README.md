# granki-corpus

Открытый корпус русских текстов для [granki-bench](https://github.com/apantin/granki-bench): общественное достояние и тексты под открытыми лицензиями (CC BY, CC BY-SA).

**Статус: сбор не начат.**

## Как устроен

- `manifest.csv` — запись на каждый файл корпуса: путь, источник, лицензия, атрибуция, автор, жанр, период, число слов, хеш, дата сбора.
- Файл без записи в манифесте в корпус не входит.
- У корпуса свои версии и теги; granki-bench записывает версию корпуса в каждом результате.

## Лицензия

Единой лицензии у корпуса нет — см. [LICENSE.md](LICENSE.md).
